🔐 Advanced Security Details & Cryptographic Ledger (Click to expand)

Continuous Hash-Chain Ledger Architecture

Every scan report is hashed to produce a canonical digest ($R_n$). Each scan is bound to the preceding record using an append-only SHA-256 hash chain:

H_n = SHA-256( R_n || H_{n-1} )

This ensures that past scan reports cannot be modified, reordered, or deleted without invalidating subsequent blocks in the ledger.

Ed25519 Digital Signatures (RFC 8032)

Each scan generates a signed cryptographic scan passport. The scanner signs the canonical JSON representation using an Ed25519 private key, allowing third parties or academic evaluators to verify report authenticity without trusting the database.
